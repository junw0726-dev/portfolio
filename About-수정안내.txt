About 스크롤 / 모바일 간격 / 드래그·우클릭 수정본

적용
Junwoo-Portfolio-About-Update.zip을 풀어 index.html이 있는 기존 웹 폴더에 파일들을 덮어쓰세요.
기존 이미지와 site-content.js, 관리 화면 데이터는 덮어쓰지 않습니다.
이전 페이지 전환 효과도 포함한 누적 수정 파일입니다.
새로고침 후 예전 모습이면 Ctrl+Shift+R로 다시 로드하세요.

최종 동작
- 데스크톱 About: 기본 스크롤바 숨김. 가로 1px × 세로 50px 직사각형으로 스크롤 위치를 표시.
- 스크롤 표시는 클릭하거나 드래그해서 조작할 수 없습니다. 마우스 휠로 본문을 스크롤하세요.
- 모바일 About: 소개글과 Experience 사이 40px → 80px.
- 모바일 About: 상단 메뉴와 소개글 사이의 실제 간격을 이전의 절반으로 조절.
- 모바일은 스크롤바와 사용자 지정 표시를 숨기고 기본 터치 스크롤을 사용합니다.
- 글자 선택: 메인 본문, 상세 팝업 본문, About 본문에서 허용.
- 상단바의 이름·메뉴·Contact 영역은 글자 선택 및 링크 드래그를 차단.
- 우클릭: About 소개글과 이력 본문에서만 허용. 상단바·메인·상세 팝업에서는 차단.
- About 글자 선택 색상: #2a2a2a 배경 / 흰색 글씨.
- 기존 페이지 전환 효과와 저작권 위아래 10pt 여백 유지.

수정 파일
style.css, ui.js

누적 적용을 위해 함께 포함한 파일
index.html, about.html, page-transitions.js

전체 파일이 필요하면 Junwoo-Portfolio-About-Full.zip을 사용하세요.

검증
1280×800: 표시 1×50px, pointer-events:none, 휠에 따라 표시 이동, 표시 클릭 시 위치 유지.
390×844: 소개글-이력 80px, 상단 간격 비율 0.5, 스크롤바 및 위치 표시 숨김, 가로 넘침 없음.
About 본문 마우스 드래그로 어두운 선택 배경과 흰색 글자 표시 확인.
실제 휴대폰의 터치 제스처는 별도로 테스트하지 않았으며 기본 브라우저 스크롤을 사용합니다.
