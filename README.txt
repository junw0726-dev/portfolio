Junwoo Lim — 포트폴리오 + 관리 웹

1. 웹 보기
index.html을 Chrome 또는 Edge에서 열면 됩니다.
사이트는 설치나 서버 없이도 표시됩니다.

2. 관리 웹 실행
start-admin.cmd를 더블클릭합니다. Node.js LTS가 설치되어 있어야 합니다.
https://nodejs.org/
자동으로 관리 페이지가 열립니다. 서버 창은 사용하는 동안 열어 두세요.
관리: http://127.0.0.1:8787/admin.html
웹: http://127.0.0.1:8787/index.html
모바일 미리보기: http://127.0.0.1:8787/mobile.html
종료하려면 서버 창에서 Ctrl+C를 누릅니다.

3. 작업물 관리
- 작업물 추가 / 삭제 / 순서 변경 / 제목 편집.
- 썸네일 슬라이드: 갤러리에서 3초마다 전환하는 사진 목록입니다.
- 팝업 상세 내용: 썸네일과 별개인 이미지·텍스트박스 목록입니다.
- 이미지와 텍스트박스를 원하는 순서로 배치할 수 있습니다.
- 텍스트박스에는 줄바꿈, 글자 크기, 정렬, 링크를 설정할 수 있습니다.
- 사진 등록에서 여러 이미지를 한 번에 선택할 수 있습니다.
- 이미지 교체는 기존 항목을 삭제하고 새 사진을 추가합니다.
- PNG, JPG, WebP, GIF 지원. 이미지 1개 최대 25MB, 전체 저장 요청 최대 150MB.
- 기존 Figma 커버는 원래의 크롭과 배치를 유지합니다.

4. About / Contact
- 소개 글과 Experience, Awards, Exhibition의 텍스트박스 추가 / 편집 / 삭제 / 정렬.
- 새 섹션도 추가할 수 있습니다.
- Contact는 줄별로 내용과 링크를 설정합니다. 한 줄 추가 / 삭제 / 정렬 가능.
- 링크를 비우면 클릭되지 않는 일반 텍스트가 됩니다.
- 링크 형식: https://..., mailto:..., tel:...

5. 저장 / 백업
우측 상단 '웹에 저장'을 누르면 이 폴더의 site-content.js에 반영됩니다.
사진은 데이터로 함께 저장되므로 원본 업로드 파일을 옮겨도 유지됩니다.
브라우저 저장소가 아닌 파일에 저장합니다. 브라우저를 껐다 켜도 유지됩니다.
저장 후 웹 또는 미리보기를 새로고침해서 확인하세요.
직전 저장본은 site-content.backup.txt로 한 개 보관합니다.
'메인 · 백업'에서 JSON 다운로드 / 가져오기 / 콘텐츠 JS 다운로드가 가능합니다.
JSON 가져오기는 편집 내용만 바꿉니다. 웹에 반영하려면 저장해야 합니다.
관리 페이지를 파일로 직접 열면 서버 저장은 사용할 수 없으며, 콘텐츠 JS 다운로드를 이용할 수 있습니다.

6. 모바일 미리보기
mobile.html은 별도 모바일 미리보기 페이지입니다.
320 / 390 / 430px, 가로 / 세로, 메인 / 작업물 / About을 선택할 수 있습니다.
실제 모바일 CSS를 iframe에서 표시합니다. 저장 후 새로고침을 누르세요.
브라우저 미리보기이므로 실제 기기의 터치·성능까지 에뮬레이션하지는 않습니다.

7. 현재 제공 방식
관리 서버는 본인 컴퓨터의 127.0.0.1에서만 실행됩니다.
온라인 호스팅에 자동 배포하는 기능은 포함하지 않습니다.
호스팅에 반영할 때는 저장한 최신 site-content.js와 웹 파일·assets를 함께 업로드합니다.
관리 서버와 관리 페이지는 공개 웹에 업로드할 필요가 없습니다.

8. 이번 버전의 웹 동작
- 중앙 80px ㅇㅈㅇ 로딩 화면 1.5초. 회전 없이 마지막에 페이드.
- About 별도 페이지, 오른쪽 정보 영역 내부 스크롤.
- 상세 패널 약 51%, 왼쪽 2열 갤러리, 패널 내부 스크롤.
- 작은 X 아이콘, 사진 프레임 위·오른쪽 각각 8px.
- 색 반전 ㅇㅈㅇ 커서. 작업물 위에서는 형태 유지, 메뉴·링크에서는 별 회전.
- 저작권 12pt, 위·아래 간격 14pt, 자간 -2%.
