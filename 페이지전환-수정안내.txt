최신 포트폴리오 페이지 전환 / 저작권 여백 수정

사용자가 제공한 '새 압축.zip + .z01 + .z02'의 최신 버전을 기준으로 수정했습니다.

수정 파일만 적용할 때
1. 기존 웹 폴더를 백업합니다.
2. Junwoo-Portfolio-Transition-Patch.zip의 파일들을 기존 index.html이 있는 폴더에 덮어씁니다.
3. 새 page-transitions.js도 같은 폴더에 포함되어야 합니다.
4. 브라우저를 새로고침합니다. 이전 모습이 남으면 Ctrl+Shift+R로 새로고침합니다.

실제 수정 파일
- index.html
- about.html
- style.css
- ui.js
- page-transitions.js (새 파일)

변경 내용
- About / 메인 이동 시 본문이 0.24초 동안 살짝 위로 사라지고, 새 본문이 0.56초 동안 부드럽게 나타납니다.
- 고정된 헤더와 메뉴는 제자리에 유지됩니다.
- 첫 방문 로딩 화면은 유지하고, 내부 페이지 이동 때는 1.5초 로딩 화면을 반복하지 않습니다.
- 브라우저 뒤로/앞으로 이동 시 본문이 숨겨진 채 남지 않도록 복원합니다.
- 프로젝트 상세 패널이 열린 상태에서 페이지를 이동할 때 패널도 함께 페이드됩니다.
- 저작권 문구 위·아래 padding은 각각 10pt (약 13.33px)입니다. 글자 크기는 기존 12pt입니다.
- 시스템에서 동작 줄이기를 사용하는 경우 전환 효과를 줄입니다.

수정 파일 묶음에는 콘텐츠 파일이나 이미지가 들어 있지 않습니다.
site-content.js, 관리 페이지, 작업물 이미지와 데이터는 기존 파일을 그대로 사용합니다.
전체 파일이 필요한 경우 Junwoo-Portfolio-Updated.zip을 사용하세요.

확인: JavaScript 문법, 실제 브라우저에서 About/메인/Work 이동, 상세 패널 동작, 저작권 여백 계산값.
